# 🎬 Netflix Clone (HTML & CSS)

A fully responsive **Netflix Landing Page Clone** built using **pure HTML and CSS only**.
This project recreates the UI of the Netflix homepage including the hero banner, navigation bar, movie sections, and footer.

The purpose of this project is to practice **layout structuring, flexbox, background images, responsiveness, and UI cloning skills** without using JavaScript.

---

## 🚀 Live Demo

Live demo: https://moviegalleryprateek.netlify.app/

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* Google Fonts

---

## 📌 Features

* Netflix-style Navigation Bar
* Hero Section with background image
* Email Signup Form UI
* Movie/Series Thumbnail Rows
* Hover Zoom Effect on Cards
* Multiple Content Sections
* FAQ Section UI
* Footer with links
* Fully Responsive Design
